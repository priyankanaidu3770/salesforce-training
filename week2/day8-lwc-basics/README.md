# Day 8 - LWC Basics

## What is LWC?
Lightning Web Components (LWC) is a modern Salesforce UI framework used to build fast and reusable web components using HTML, JavaScript, and CSS.

LWC follows modern web standards and helps developers create efficient enterprise applications.

---

## Why Salesforce Uses LWC
- Better performance
- Reusable components
- Faster loading
- Modern JavaScript support
- Easy maintenance
- Secure architecture

---

## Your UI Screens
UI screens are the pages users interact with in Salesforce applications.

Examples:
- Login Page
- Dashboard
- Account Page
- Contact Form
- Product List

---

## Component Breakdown
A large application is divided into smaller reusable components.

Example:
Dashboard Page
- Header Component
- Sidebar Component
- Profile Component
- Notification Component

This approach improves maintainability and reuse.

---

## Frontend vs Backend Logic

### Frontend
Handles:
- UI
- Buttons
- Forms
- User interactions

Technologies:
- HTML
- CSS
- JavaScript
- LWC

### Backend
Handles:
- Database operations
- Business logic
- Security
- Server-side processing

Technologies:
- Apex
- Salesforce Database

---

## Reflection
LWC helps developers build modular, secure, and scalable applications.

Separating frontend and backend improves:
- Performance
- Security
- Code maintenance
- Team collaboration
