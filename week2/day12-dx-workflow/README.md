# day12-dx-workflow

## What is Salesforce DX?
Salesforce DX is a modern development approach for Salesforce applications using source-driven development, CLI tools, scratch orgs, and version control.

---

## Why CLI Matters
- Faster development
- Automation support
- Easy deployments
- Better productivity
- Useful for enterprise workflows

---

## Why GitHub Matters
GitHub helps teams:
- Store source code
- Track changes
- Collaborate safely
- Maintain version history
- Manage deployments

---

## Team Collaboration Problems
Without collaboration tools:
- Code conflicts occur
- Changes get overwritten
- Tracking becomes difficult
- Deployment errors increase
- Team productivity decreases

---

## Enterprise Workflow Discussion
Enterprise workflows use:
- Salesforce DX
- CLI tools
- GitHub repositories
- Branching strategies
- Testing pipelines
- Deployment validation

This improves scalability, reliability, and collaboration.

---

## Reflection
Today I learned how Salesforce DX, CLI tools, and GitHub improve enterprise development workflows. I also understood the importance of collaboration, version control, and source-driven development in large projects.
